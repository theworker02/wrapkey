# wrapkey

Wrap filesystem key paths across POSIX and Windows conventions.

**Site:** https://theworker02.github.io/wrapkey/

## Install / run

```bash
git clone https://github.com/theworker02/wrapkey.git
cd wrapkey
node src/cli.js
node --test
```
